# CurseForge icon provenance

`icon.png` is a 512×512 icon for this addon. Its central Philosopher's Stone is from KURONAMI's existing EMC series master sprite. The purple frame was drawn by this addon's maintainers; it does not contain Apotheosis JAR pixels. The Apotheosis 8.9.0 JAR declares its assets All Rights Reserved, so comparison candidates using those assets are not distributed here.

This branding PNG is a separate CurseForge avatar candidate. It is not embedded in the current 0.1.0 JAR.
